# 从角色想法到已选图片

本页连接“想做什么角色”和后续 SVG/APNG 制作。Codex 内置生图、用户指定的图像 API、手绘或已有图片都可以进入同一流程；最终交给后续步骤的是**用户已选的本地图片文件**，不是某个服务的任务号或一段提示词。

## 先确定要画什么

从用户已有设定提取角色身份：主体拓扑、脸与表情、比例、配色、服装或表面纹样、描边，以及不可改的特征。再读目标运行时的显示尺寸、画布比例、贴边方式和最大动作范围，给完整身体、附属物和道具留空间。缺少关键设定时再问；已经给出的设定不要重新替用户决定。

为每张输入图标明职责：

- **身份图**决定这个角色是谁；已有且获选时直接沿用，没有时先生成概念方案并选定一张母图。
- **结构图**帮助看侧面、背面、连接点和遮挡，不自动覆盖身份图。
- **姿势图**说明这次动作的重心、手势和接触关系，不负责重新设计脸与服装。
- **道具图**锁定道具外形、数量和材质；需要后期写字的表面先留白。

## 选择生图入口

| 来源 | 怎么做 | 能力边界 |
| --- | --- | --- |
| Codex 内置生图 | 当前环境可用且用户没有指定别的渠道时，用内置图像生成/编辑能力创建方案或修改已选图；编辑本地图片前先打开查看。把获选成品复制到项目内。 | 不要求 API key；内置工具是否可用取决于当前环境。 |
| 图像 API | 使用用户指定且当前可用的服务。仓库的 [`gen-images.js`](../routes/apng/tools/README.md) 目前仅是豆包文生图示例；其他 API 或带参考图的编辑使用该服务自己的客户端，保存结果为本地图片再进入下节。 | 不把 `--api doubao` 说成通用适配器；模型、参数、费用和编辑能力按实际服务核对。凭据留在本机配置，不写入图片记录或仓库。 |
| 已有或手绘图片 | 先检查授权使用范围、实际像素、透明度与构图，再按同一标准挑选身份图和关键帧。 | 无须为了走流程重新生成。 |

无论入口，生成请求只在用户授权的批次内执行；用户指定了工具或 API 就沿用，不静默换渠道。API 请求失败或结果不明时，先查原任务是否成功，避免重复付费。

## 从母图生成姿势与关键帧

1. **选身份母图。** 没有现成角色时，先出能比较脸、轮廓、比例和画风的方案；只把用户选中的版本当后续身份依据。必要的侧背面图用来补结构。
2. **一次只改明确的目标。** 生成新姿势时把身份母图作为身份依据；姿势草图只借动作。编辑已有图时写清“改什么、哪些不变”，不要让上一张尚未获选的候选图自动成为新母图。
3. **按用途做输出。** SVG 路线通常需要可检查的透明 PNG，再整理成可动画的分层 SVG；APNG 路线准备已选首帧、尾帧和必要的共同中间帧，背景按实际视频/抠图路线选择。透明底与纯色色键底不是同一要求。
4. **检查与选定。** 在目标桌宠尺寸看角色是否认得出、动作是否读得懂；放大看结构、手和接触点、描边与裁切。把候选与已选母图叠图，按稳定轮廓和接触线核对主体尺度及位置；扩画布后即使输出像素尺寸不变，人物也可能在画面中变小，需重新核对占比和留白。检查纯色底是否真的均匀、文件是否带 alpha；SVG 路线能直接得到合用的透明图时无须强加色键底。若任务要求只改局部，用差异图核对目标区域外的像素不变；生成器做不到时换用可控编辑并说明差异。技术上可用、用户选中、视频输入就绪分别记录。

给生成器的说明可按下面的短骨架填写，不必固定用词或固定方案数：

```text
用途：身份母图 / 姿势方案 / 首帧 / 尾帧 / 中间帧
输入图职责：图1 是已选身份依据；图2 只借姿势或结构（按实际输入填写）
这次要画：角色可观察的姿势、表情、动作意图和道具关系
必须保留：已选的脸、比例、配色、服装、描边及其他识别特征
只允许变化：本次指定的部位、姿势或表情
画布：目标比例、人物尺度、位置、动作留白和背景/透明要求
避免：裁切、额外肢体或道具、文字水印，以及本次已知的失败模式
```

## 交给后续路线的文件

把获选图片放在项目内，保存可直接读取的本地路径，并记录用途、来源方式、所用身份/姿势参考、画布尺寸、背景或 alpha、版本及用户选择。API 模型和任务标识若可获得，也记在项目自己的制作记录里；不要求所有来源都伪造同样的字段。

- SVG 路线读取已选透明 PNG，再按角色复杂度做矢量化或分层重画。
- APNG 路线读取已选首尾图片；仓库现有 `gen-video.js` 可用 `--image`、`--last-frame` 读取本地路径，**其视频 API 仍只支持豆包**。其他视频服务应使用各自的客户端，并同样核对实际请求的首尾输入位。

因此接入新的**图像** API 时，先让它输出本地图片并走同一选图检查即可；无需修改本仓库的视频脚本，也不能把一个尚未支持的服务名传给 `--api`。

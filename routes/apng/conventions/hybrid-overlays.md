# APNG 与 SVG 混合合成

生成视频擅长自然、有机的运动；SVG 擅长精确、可复用、可单独调节的内容。桌宠状态可以混合两者，不必把整个效果强行塞进单一路线。

## 适合保留在视频层的内容

- 呼吸、眨眼和自然表情；
- 头发、衣袖、毛发和软组织摆动；
- 云雾、烟尘和难以参数化的有机运动；
- 身体重心、走路和复杂接触动作；
- 自然光影与柔和阴影。

## 适合放在矢量层的内容

- 需要准确显示的文字、符号和纹样；
- 符纸、卷轴等留白区域上的内容；
- 铃铛声波、提示线、脚步弧光；
- 可控粒子、描边、金色发光和状态提示；
- 需要跨状态复用或随主题换色的效果。

这是一组判断标准，不是要求所有动画都添加 SVG。自然运动已经完整时，可以只交付 APNG。

## 先生成留白表面

模型难以稳定生成可读文字和精确符号。需要准确内容时，参考图和视频应保留干净的空白区域，再在后期添加矢量层。提示词应锁定纸张或卷轴的尺寸、透视、边框和折叠方式，同时要求内部无文字、无随机图案。

## 逐帧锚点

矢量层必须跟随成片中的实际位置，而不是根据理论动作猜轨迹。对每一帧或足够密集的关键帧记录：

- 锚点位置；
- 旋转角度；
- 缩放与透视；
- 可见范围；
- 与手、身体和道具的前后遮挡关系。

只有实测运动足够平滑时，才在稀疏关键帧之间插值。若符号或粒子出现跳动，应增加实测点，而不是叠加更强的缓动掩盖误差。

## 共用帧时钟

视频帧、透明人物层和 SVG 层应由同一帧索引或同一时间轴驱动。变速、裁帧或拼接后，必须同步更新矢量层时间：

- 不使用独立、近似的 CSS 周期猜测视频进度；
- 首尾需要消失的粒子应在边界处归零；
- 循环时检查最后一帧到第一帧的特效连续性；
- 一次性动作结束后按运行时语义隐藏、保持或重置效果。

## 合成验收

分别检查人物底片和完整合成。完整合成需要连续播放确认：

- 符号是否贴在道具表面；
- 粒子是否从正确位置出现；
- 遮挡关系是否符合动作；
- 特效是否抢过角色主体；
- 调色、alpha 与帧时长是否在合成后保持一致。

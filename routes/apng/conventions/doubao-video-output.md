# 豆包 Seedance 视频画幅与参考图约定

> 本页记录 APNG 路线所依赖的官方输出规格和构图约束。规格核对日期：2026-09-05。模型能力可能更新，实际生成前请再次查看官方文档。

## 先选比例，再制作参考图

豆包的 `resolution` 是清晰度档位，不能单独决定输出像素。最终尺寸由 `resolution` 与 `ratio` 共同决定。

同一套桌宠动画应先选定一个比例，然后让主参考图、各状态首帧、尾帧和输出视频全部保持这个比例。若上传图片的比例与请求的 `ratio` 不同，火山方舟会以图片中心为基准裁剪，不会补边。首尾帧比例不同时，以首帧为准裁剪尾帧。

不要先画任意大小的画布，再依赖视频接口改成目标比例。中心裁剪可能切掉头饰、脚、尾巴、兵器、衣袖或动作所需留白。

## 当前默认模型：Seedance 1.5 Pro

工具默认使用 `doubao-seedance-1-5-pro-251215`。该模型支持 480p、720p、1080p，以及 `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive`。

桌宠制作最常用的三种比例及实际输出像素如下：

| 比例 | 480p | 720p | 1080p | 常见用途 |
|---|---:|---:|---:|---|
| `1:1` | 640×640 | 960×960 | 1440×1440 | 同时容纳横向和纵向动作 |
| `3:4` | 560×752 | 834×1112 | 1248×1664 | 全身站立、悬浮、跳跃等纵向动作 |
| `4:3` | 752×560 | 1112×834 | 1664×1248 | 挥剑、甩袖、横向移动等横向动作 |

其他支持尺寸：

| 比例 | 480p | 720p | 1080p |
|---|---:|---:|---:|
| `16:9` | 864×496 | 1280×720 | 1920×1080 |
| `9:16` | 496×864 | 720×1280 | 1080×1920 |
| `21:9` | 992×432 | 1470×630 | 2206×946 |

`4k` 不是 Seedance 1.5 Pro 的可用档位。CLI 接受 `4k` 是为了允许调用者覆盖到支持该档位的模型；模型与档位的兼容性仍由服务端校验。

`adaptive` 会让模型根据输入自动选择比例。它适合保留已经确定的参考图比例，但不应替代项目内的画布规范。批量制作时仍应把比例写入配置，方便审查和复现。

## 输入图片要求

Seedance 1.5 Pro 的单张输入图片应满足：

- 宽高比（宽 ÷ 高）在 0.4 到 2.5 之间；
- 宽、高各自在 300 到 6000 px 之间；
- 单张小于 30 MB；
- 支持 jpeg、png、webp、bmp、tiff、gif、heic、heif。

首帧图生视频传 1 张图片。首尾帧生视频传 2 张图片，并分别指定 `first_frame` 和 `last_frame`。需要无缝循环时，首尾帧可以使用同一张图片。

## 桌宠画布选择

选比例时先画出整套动画的最大运动范围：

1. 标出角色中性姿态的脚底线、头顶线和中心轴。
2. 叠加最高悬浮或跳跃位置。
3. 叠加最宽的兵器、衣袖、尾巴、法阵或粒子效果。
4. 选择能容纳整个运动范围的官方比例。
5. 所有参考图保持相同画布、人物尺度、中心轴和脚底线。

`1:1` 通常是横纵动作都存在时的稳妥选择；`3:4` 更适合纵向动作占主导的角色；`4:3` 更适合横向招式占主导的角色。比例确定后，可以先用 720p 试动作，再用同一比例生成 1080p 正式版本。

## 命令示例

显式选择 1080p、1:1，并请求固定镜头：

```powershell
node gen-video.js thinking `
  --image reference/thinking.png `
  --last-frame reference/thinking.png `
  --resolution 1080p `
  --ratio 1:1 `
  --camera-fixed
```

批量配置也支持相同字段：

```json
{
  "delayMs": 60000,
  "jobs": [
    {
      "key": "thinking",
      "image": "reference/thinking.png",
      "lastFrame": "reference/thinking.png",
      "resolution": "1080p",
      "ratio": "1:1",
      "cameraFixed": true
    }
  ]
}
```

省略这些选项时，工具不会伪造模型能力，而是让豆包使用该模型的服务端默认值。
